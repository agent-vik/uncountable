展厅 2

The Paradox

悖论

1638 年，伽利略比较了两串数字。

第一串，是自然数——从 1 开始，每个数加 1：

自然数

完全平方数

第二串，是完全平方数——某个自然数的平方：

1²=1, 2²=4, 3²=9, 4²=16, 5²=25, …

向下滚动 ↓
角度一

亲手数一数：平方数有多少？

下面是前 50 个自然数。
你觉得哪些是完全平方数？点出来试试。

0 你圈出的平方数
0 你漏掉的
0 圈错的

在前 50 个自然数里，只有 7 个 平方数（1, 4, 9, 16, 25, 36, 49）。

其余 43 个都被跳过了。

换一个范围呢？

平方数 被跳过

结论一：平方数比自然数少。越往后越稀疏，几乎全是被跳过的。

角度二

换一个角度：每个数都能配上吗？

如果每个自然数都能配上一个平方数，那它们就一样多。

规则很简单：输入任何自然数 n，它的平方就是 n²。

试试看——能不能找到一个配不上的数？

你试了 0 个数，每一个都配上了。

再试几个？或者——你觉得能找到一个配不上的吗？

事实上，任何自然数 n 都有对应的 n²。这条规则没有例外。

结论二：平方数和自然数一样多。每一个都能配上，一个不少。

碰撞

悖论

角度一

平方数比自然数少

它们是子集，大量数字被跳过

vs

角度二

平方数和自然数一样多

它们能一一配对，一个不多一个不少

两个结论都对。但它们矛盾。

部分怎么能等于整体？

伽利略的反应是："无限不可比较。"

他选择了转身走开。

展厅 3

The Question

提问

250 年后，格奥尔格·康托尔问了一个人没问过的问题：

所有的无穷，都一样大吗？

他先问了一件具体的事：0 和 1 之间的小数，能排成一张表吗？
试着写几个 0 到 1 之间的小数（建议至少 8 个）。

你的列表是空的。开始写吧。

你已收集了 0 个数字

这张表声称包含了 0 到 1 之间的所有小数。

往下滚动，表格似乎没有尽头……

展厅 4

The Diagonal

对角线

康托说："让我看看这张表的对角线。"

点击按钮，看康托如何找到对角线。

把对角线上的数字拎出来，每个加 1。
如果到 9 就变成 0。

新数字： 0.

我们刚刚造了一个新的小数。它在这张表里吗？

新数字： 0.

没有一行能匹配。不管你往表里加多少数进去，这个新数字永远不在表里。因为表里每个数字总有至少一位和这个新数字不一样，那必然就不是同一个数。

展厅 5

The Consequence

后果

这个新数字不在表里。

但表声称包含了所有小数。

矛盾。

所以——那张表从来就不完整。

不管你怎么排，对角线每位 +1 总能造出一个不在表里的数字。

排成表，意味着每个小数都有一个编号——

第 1 个、第 2 个、第 3 个……

但现在证明了：小数排不成表。

总有一些小数，拿不到任何编号。

还记得伽利略吗？

能配对，就是一样多。

配不上——就是更多。

自然数

1, 2, 3, 4, 5, …

✓ 能排成表

每个数都有编号：
第 1 行、第 2 行、第 3 行……

无穷

vs

0 到 1 之间的小数

0.3, 0.14, 0.827, …

✗ 排不成表

总有数拿不到编号：
对角线总能造出漏网的

无穷，但更大

0 到 1 之间的小数，

比所有的自然数还要多。

不是多一个两个。

是多到排不进任何一张表。

无穷，也有大小之分。

有的无穷，比另一些无穷更大。
